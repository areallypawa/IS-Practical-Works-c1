# 🧮 Практическая работа №3 - «Двумерные статические массивы. Указатели» (C++)

## 📌 Описание
Данный репозиторий содержит реализацию практической работы №3 по дисциплине **Программирование (C++)**.  
Работа посвящена изучению **двумерных статических массивов** и **арифметики указателей** при работе с ними.

Программа представляет собой **консольное приложение с интерактивным меню**, позволяющее заполнять, преобразовывать, сортировать и обрабатывать квадратную матрицу.

---

## 🎯 Цель работы
- Освоить работу с двумерными статическими массивами
- Научиться использовать **арифметику указателей** для доступа к элементам матрицы
- Реализовать алгоритмы заполнения, перестановки блоков и сортировки
- Закрепить навыки обработки данных в матрице

---

## 🛠 Используемые технологии
- Язык программирования: **C++**
- Компилятор: **MSVC / MinGW**
- Платформа: **Windows**
- Библиотеки:
  - `<iostream>`
  - `<Windows.h>`
  - `<conio.h>`

---

## 📐 Параметры программы
- Тип массива: `int`
- Размер матрицы: `N x N`
- Значение `N`: **6** (можно изменить на 8 или 10)
- Диапазон случайных чисел: `1 ... N*N`

---

## 📋 Функциональные возможности

### 🔹 1. Вывод матрицы
Отображение текущего состояния матрицы в консоли.

---

### 🔹 2. Заполнение матрицы
Заполнение выполняется **исключительно с использованием арифметики указателей**.

#### 📍 Схемы заполнения:
- 🌀 **Спираль**
- 🐍 **Змейка**

Процесс заполнения **анимирован** (пошаговый вывод с задержкой).

---

### 🔹 3. Перестановка блоков матрицы
Матрица делится на 4 блока (A, B, C, D), после чего выполняется их перестановка.

#### 🔄 Доступные схемы:
- Перестановка по квадрату
- Перестановка по кресту
- Вертикальные параллельные блоки
- Горизонтальные параллельные блоки

---

### 🔹 4. Сортировка элементов
Сортировка всех элементов матрицы как линейного массива `N*N`.

#### 📌 Реализованный алгоритм:
- **Bubble Sort (пузырьковая сортировка)**

---

### 🔹 5. Арифметические операции
Ко всем элементам матрицы применяется выбранная операция:

- ➕ Сложение
- ➖ Вычитание
- ✖ Умножение
- ➗ Деление (с защитой от деления на ноль)

---

### 🔹 6. Индивидуальное задание (IDZ)
- Заполнение матрицы случайными числами
- Вычисление:
  - сумм строк
  - сумм столбцов

---
