# 🧮 Практическая работа №4 - «Тип данных string. Работа со строковыми типами данных» (C++)

## 📌 Описание проекта
Данная программа реализует обработку строковых данных на языке C++ с использованием
стандартного типа данных `string`.  
Программа позволяет вводить текст с клавиатуры или из файла, выполнять его нормализацию,
а также решать ряд задач по анализу и преобразованию строк.

Проект разработан в рамках лабораторной работы по дисциплине «Программирование».

---

## ⚙️ Функциональные возможности

### 🔹 Ввод данных
- Ввод текста с клавиатуры
- Чтение текста из файла
- Текст состоит из 1–50 слов
- Каждое слово содержит от 1 до 10 строчных латинских букв и/или цифр
- Между словами допускается произвольное количество пробелов
- Ввод завершается точкой

---

### 🔹 Нормализация текста
- Удаление лишних пробелов
- Удаление лишних знаков препинания  
  (несколько подряд идущих, кроме корректного многоточия `...`)
- Приведение всех букв к нижнему регистру

---

### 🔹 Обработка слов
- Разделение слов по категориям:
  - слова, содержащие только буквы
  - слова, содержащие только цифры
  - слова, содержащие и буквы, и цифры
- Подсчёт количества символов в каждом слове (без учёта пунктуации)

---

### 🔹 Поиск подстроки
Реализованы два алгоритма поиска подстроки:
- Линейный (наивный) поиск
- Алгоритм Кнута–Морриса–Пратта (КМП)

Для каждого алгоритма выводится индекс начала найденной подстроки.

---

## 🧠 Используемые технологии
- Язык программирования: **C++**
- Стандартные библиотеки: `<string>`, `<sstream>`, `<fstream>`, `<chrono>`
- Работа с консолью Windows (`Windows.h`, `conio.h`)
- Алгоритмы обработки строк
